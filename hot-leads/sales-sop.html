Fast SOP

  1. Open the lead page below.
  2. Record a 30-60 second Loom walking the hero, reviews, transformation clip, and call path.
  3. Text the link with the lead-specific text line from the queue.
  4. Call back 1-2 hours later or the next day using the saved script angle.

Guardrail

  • `Needs review cleanup` means the page exists and is usable, but review snippets should be swapped before sending if time allows.
  • The shared pool transformation clip is already wired into every demo.
