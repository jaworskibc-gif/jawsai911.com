# JAWSAI911 Proposal System

Use these two files as the default client package:

- `client-proposal-template.html`
- `client-blueprint-template.html`

## Standard package

Every client should receive:

1. A short proposal
2. A 1-page blueprint

The proposal sells the engagement.
The blueprint makes the system easy to understand fast.

## Recommended proposal structure

1. Cover
2. Current leakage
3. Solution stack
4. Website + intake plan
5. Impact + business case
6. Investment + rollout
7. Close

## Recommended blueprint structure

1. The problem
2. The solution
3. AI agent stack
4. The impact
5. Investment
6. Closing / CTA

## What to customize first

Replace all bracketed placeholders:

- `[Client Name]`
- `[NICHE]`
- `[City / State]`
- `[Offer]`
- `[Problem]`
- `[Impact]`
- `[Pricing]`
- `[Rollout]`

## Best use by niche

- Dealerships: lead response, inventory, reviews, BDC, smart site, credit app path
- Insurance: enrollment, compliance, agent assist, CRM flow, follow-up
- Medical / chiropractic: trust, appointment path, missed-call recovery, review engine, local SEO
- Law offices: consult intake, call routing, trust, follow-up, city pages
- Real estate: listing leads, valuation leads, text-back, reviews, local authority pages

## Rule

The homepage direction for a custom client site should match page 1 of the proposal whenever possible.
