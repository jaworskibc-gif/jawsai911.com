Dialer + Live Script

Queue the next number, load his pitch, and launch the dialer from the same screen.

The dialer button uses the phone number field and opens the device dialer with a `tel:` link. When `hub-config.js` is connected to Supabase, this script becomes part of Arron’s shared workspace and will be there when he signs in later.

Docs + Screenshots

Next-Day Handoff

Create an explicit package for Arron to open the next morning. This is optional once shared Supabase sync is enabled, but it still works as a manual send-off step.

Use this when you want to give him tomorrow’s script, tasks, appointments, and training videos. Send him the generated link by text or email, and when he opens it this page can load that package into his browser.
