CRM Core

Main rep screen for queue, current lead, send path, and call logging.
Lead Detail
Review the lead, preview the SuperSite, send outreach, create proposal/invoice, and set follow-up.
Pipeline
See all leads by stage and import or clean up records when needed.
Dashboard
High-level CRM counts, due follow-ups, recent calls, and lead volume.
Client Packages

Create package proposals and save them into the estimate flow.
Invoicing & Estimating
Create invoices, estimates, and billing records tied to the lead.
Sales Documents
Store receipts, docs, proofs, and package attachments.
Site Builder
Only for building or editing a client deliverable.
Form Builder
Only for adding client package forms or intake assets.
Ops Tools
