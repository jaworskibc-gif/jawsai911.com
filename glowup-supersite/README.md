# GlowUP SuperSite

Rebuilt from [glowupbeautysolutions.netlify.app](https://glowupbeautysolutions.netlify.app/) as a **double-stacked SuperSite**:

| Layer | File | What it is |
|-------|------|------------|
| **1 · Site Agent** | `index.html` | Converting marketing SuperSite + 2026 social/local trends |
| **2 · Command Hub** | `command.html` | CRM, Gen-Viral, Social Engine, Google Review Lane, Photo → 5 Lanes |

## Deploy

```bash
cd glowup-supersite
# Netlify drop folder, or:
npx netlify deploy --dir=. --prod
```

## Walkthrough

1. Public: problems → double stack → features → social trends → CTA  
2. Command Hub: recovery, Gen-Viral, reviews, CRM  
3. Compare to original GlowUP for visual lineage
